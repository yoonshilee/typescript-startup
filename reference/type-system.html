TypeScript 类型系统速查

类型描述可接受值与值之间的关系；它们在运行前服务于检查器，并在执行前被移除。

REFERENCE 03 / 06 · 第 05–12 课配套

先推断，边界再标注

const title = "Release"; // inferred as "Release"
let status = "active";   // inferred as string

function archive(id: string): boolean {
  return id.length > 0;
}

局部值通常让编译器推断；函数参数、公开返回契约和数据边界显式标注。标注太多会重复信息，标注太少会让公开接口含糊。

保留字面量精度

工具用途边界
as const把表达式推断为只读、精确字面量是静态约束，不冻结运行时对象
satisfies检查表达式满足目标类型，同时保留自身精度不进行运行时校验
显式标注把变量或返回值限制在某个公开类型可能主动拓宽局部精度

对象形状

type NoteStatus = "active" | "archived";

interface Note {
  readonly id: string;
  title: string;
  body?: string;
  status: NoteStatus;
}
  • 可选属性 body? 表示属性可能不存在；它不等于必须存在但值可为 undefined。
  • readonly 阻止通过该类型位置赋值，是浅层静态约束，不是 Object.freeze。
  • TypeScript 主要按结构判断兼容：成员足够即可，不要求声明名相同。
  • type 擅长联合、交叉和类型表达式；interface 擅长命名对象契约。不要为风格战争来回转换。

联合与交叉

type LoadState =
  | { kind: "idle" }
  | { kind: "loaded"; count: number }
  | { kind: "failed"; message: string };

type Timestamped = { createdAt: string };
type SavedNote = Note & Timestamped;

联合 A | B 表示值属于候选之一；交叉 A & B 要同时满足两边。复杂状态优先判别联合，不用一组互相矛盾的 optional boolean。

关键类型

类型含义默认态度
unknown值存在但尚未验证边界默认，用检查收窄
any基本退出类型检查避免；迁移时局部隔离
never没有可能值穷尽分支与不会返回的函数
null显式空值放入联合才允许
undefined缺失/未提供索引、可选属性与无返回处常见

常用工具类型

类型作用示例
Partial<T>所有属性变可选局部更新输入
Required<T>所有属性变必需规范化后的内部模型
Readonly<T>所有属性变只读只读视图
Pick<T, K>选出部分属性列表摘要
Omit<T, K>排除部分属性创建前输入
Record<K, V>键集合映射到值固定状态到标签
ReturnType<F>取得函数返回类型从既有函数派生

工具类型用于表达真实关系，不用于隐藏简单对象。能直接读懂的五行对象类型通常比嵌套类型运算更好。

静态测试

// @ts-expect-error — number must remain rejected.
archive(42);

@ts-expect-error 只有下一行确实产生类型错误时才通过，因此可用于锁定“错误调用必须被拒绝”的负面契约。不要用它压住未理解的错误。
