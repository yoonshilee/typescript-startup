会修改原数组的常见方法

push、pop、shift、unshift、splice、sort、reverse 会修改原数组。map、filter、slice、concat、toSorted、toReversed 返回新数组。

const updated = {

展开是浅复制；嵌套变化的每一层都要显式复制。

函数与参数

  • 函数是一等值：可存储、传入、返回。
  • 参数都按值传递；对象值里保存引用，所以可以经引用修改共享对象。
  • let / const 是块级作用域；变量按源码嵌套位置查找。
  • 闭包让函数持续访问创建时可见的词法绑定。
  • 防卫分支早返回，主路径通常更清楚。

最小诊断清单

  1. 这是静态诊断还是运行时异常？
  2. 表达式实际产生了什么值？用 typeof 只作初步观察。
  3. 条件是否依赖了 truthiness，而业务需要更精确的谓词？
  4. 两个变量是否指向同一对象？哪个操作修改了原值？
  5. 数组方法返回的是新数组、元素、boolean，还是新长度？
