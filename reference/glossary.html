语言与运行时

术语本课程中的含义不要混淆
JavaScript决定值、对象、函数与异步代码如何运行的语言不是只在浏览器中的脚本
TypeScriptJavaScript 加静态类型语法、检查器与工具链不是独立运行时
Node.js执行 JavaScript 并提供文件、进程、网络等 API 的运行环境不是 TypeScript 编译器
运行时程序实际执行时的值、控制流、I/O 与失败静态类型诊断
类型剥离删除可擦除 TypeScript 类型语法后执行剩余 JavaScript完整类型检查
编译把 TypeScript 转换成可分发 JavaScript 与 source map业务测试

值、对象与函数

术语短定义快速例子
值运行时被计算、保存、传递或返回的实际数据42、"note"、{}
绑定作用域中的名字与当前值之间的关联const title = "A"
原始值非对象的不可变值string、number、boolean、null 等
对象身份对象作为独立实例的引用身份{} !== {}
词法作用域变量可见性由源码嵌套位置决定内层函数向创建位置外层查找
闭包函数与其创建时可访问词法环境的组合返回函数仍读取外层绑定
副作用除返回值外可被外界观察的变化打印、写文件、修改共享对象
不可变更新返回包含变化的新值，不改输入值{ ...note, status: "archived" }
