前置回忆：函数的形状并不陌生

你已经在 Java 或 Python 中写过“接收输入，返回结果”的函数。TypeScript 的第一步不是理解一套新运行机制，而是先认出同一结构换了哪些符号。

// Java
String formatWelcome(String name) {
  return "Welcome, " + name + ".";
}

# Python
def format_welcome(name: str) -> str:
    return f"Welcome, {name}."

// TypeScript
export function demoWelcome(): string {
  function buildWelcome(name: string): string {
    return `Welcome, ${name}.`;
  }

  return buildWelcome("Ada");
}

外层案例不需要调用者准备参数；固定样例放在函数内部。先观察内部 TypeScript helper 并回答：

  1. 函数名在哪里？
  2. 参数名和参数类型分别是什么？
  3. 哪个 string 描述返回值？

模板字符串把文本和表达式组合起来

仍看上面的 buildWelcome：模板字符串使用反引号，${name} 把参数值嵌入文本，所以本例返回 Welcome, Ada.。外层案例负责固定调试输入，内部 helper 保留 Lab 所需的参数语法。

阅读顺序：先找声明关键字与名字，再读类型，最后读等号右侧或函数体。不要试图一次解释整行。
本课先学会读和写。执行链、类型擦除与 Node 的角色会在语言基础稳定后再解释。

详细心智模型：先把一行代码拆成可识别的语法部件

1. 用 const 和 let 声明变量

export function demoVariableBindings(): string {
  const courseName: string = "TypeScript";
  let lessonNumber: number = 1;

  lessonNumber = 2;
  return `${courseName}: lesson ${lessonNumber}`;
}

const 用于不重新赋值的变量，let 用于之后需要重新赋值的变量。变量名后面的 : string 和 : number 是类型标注，等号右侧是初始值。

2. 先掌握三种常用基础类型

3. 函数声明同时写出输入、输出和处理步骤

export function demoDouble(): number {
  function double(value: number): number {
    return value * 2;
  }

  return double(3);
}

demoDouble 是可直接运行的无参案例；内部 double helper 接收数字参数。value: number 声明参数类型，右括号后的 : number 声明返回值类型，最后一行用固定样例 3 调试它。

从声明到函数的三个示例

示例 A：标注与初始值保持一致

export function demoLessonInfo(): string {
  const lessonTitle: string = "Basic syntax";
  const lessonNumber: number = 1;
  const published: boolean = true;

  return `${lessonNumber}: ${lessonTitle}, published=${published}`;
}

冒号左侧是变量名，右侧是类型；等号后是这个变量当前保存的值。三个声明分别表达文本、数字和布尔状态。

示例 B：参数和返回值可以使用不同类型

export function demoTextCheck(): boolean {
  function hasText(value: string): boolean {
    return value.length > 0;
  }

  return hasText("TypeScript");
}

内部 helper 接收字符串并返回布尔值。参数类型写在参数名后，返回类型写在右括号后；外层案例使用固定字符串调用它。

示例 C：模板字符串可以包含多个表达式

export function demoLessonDescription(): string {
  function describeLesson(title: string, minutes: number): string {
    return `${title} takes ${minutes} minutes.`;
  }

  return describeLesson("Basic syntax", 70);
}

内部 helper 的两个占位位置分别读取 title 和 minutes。固定空格和句点也是返回值的一部分。

常见误区

  1. 把基础类型写成 String、Number。 本课程使用小写的 string、number 和 boolean。
  2. 默认使用 let。 如果名字不需要重新赋值，先使用 const；需求变化时再改成 let。
  3. 忘记返回值。 写了 : string 不会自动产生字符串；函数体仍需要 return。
  4. 用普通引号写插值。 "Welcome, ${name}." 不会形成模板插值；需要使用反引号。
  5. 忽略精确输出。 空格、大小写和末尾句点都属于函数返回值。

折叠完整答案与逐行解析

显示完整答案 
export function formatWelcome(name: string): string {
  return `Welcome, ${name}.`;
}
第 1 行
export 让测试可以导入函数；参数名是 name，参数与返回值都标注为 string。
第 2 行
return 返回结果；模板字符串把固定文本、name 和末尾句点组合起来。
第 3 行
右花括号结束函数体。
