函数也是值，泛型保存值之间的类型关系

函数可以存进变量、作为参数传入、从另一个函数返回。函数类型描述它怎样被调用；泛型参数把多处类型位置连接起来，而不是像 any 一样抹掉信息。

任务卡

完成物：实现泛型高阶函数 createFilter<T>(predicate)，返回一个接收只读 T 数组并产生新 T 数组的过滤函数。

  • 跟踪回调何时被保存、调用以及返回值如何被使用。
  • 用泛型参数表示输入、回调与输出之间的同一类型关系。

前置回忆：第 03 课已经返回过函数

export function demoPrefixes(): string {
  function createPrefixer(prefix: string): (value: string) => string {
    return (value: string): string => `${prefix}:${value}`;
  }

  const prefixNote = createPrefixer("note");
  return prefixNote("draft");
}

运行时顺序是：调用 createPrefixer，创建并返回箭头函数；返回函数闭包保留 prefix；变量 prefixNote 保存函数值；最后调用该值并传入 draft。本课把此前写在返回类型里的 (value: string) => string 系统展开。

详细心智模型：描述调用方式，再连接类型位置

1. 函数类型表达式描述怎样调用一个函数值

type TitleFormatter = (title: string) => string;

export function demoFunctionType(): string {
  const formatTitle: TitleFormatter = (title) => title.trim().toUpperCase();
  return formatTitle(" Draft ");
}

(title: string) => string 左侧是参数列表，右侧是返回类型。这里的 title 名称用于阅读，真正参与兼容性检查的是参数位置和类型。函数类型中的参数名不能省略：(string) => string 会被解释成参数名叫 string、类型隐式为 any。

2. 上下文类型会反向推断回调参数

export function demoContextualTyping(): string[] {
  const titles = ["Draft", "Release"];
  return titles.map((title) => title.toUpperCase());
}

map 的声明已经说明回调第一个参数是数组元素。TypeScript 从 string[] 反向知道 title 是 string，所以无需重复标注。运行时仍是 Array.prototype.map 依次调用回调并收集返回值；类型推断不会生成额外循环。

函数参数更少可以忽略接收方提供的额外值

map 在运行时还会提供 index 与原数组，但回调只声明 title。JavaScript 会忽略多出来的实参，因此不必为了“匹配三个参数”写无用占位符。

3. 回调是由接收方决定调用时机的函数参数

export function demoCallback(): string[] {
  function transformTitles(
    titles: readonly string[],
    transform: (title: string) => string,
  ): string[] {
    return titles.map(transform);
  }

  return transformTitles([" Draft ", " Release "], (title) => title.trim());
}

调用 transformTitles 时传入两个值：数组和函数。transformTitles 没有立刻得到转换结果；它把每个元素交给 transform，并收集每次返回的 string。回调类型既限制接收方如何调用，也限制调用方能传入什么函数。

4. 回调参数可选表示接收方真的可能不传

export function demoCallbackIndex(): string[] {
  function labelValues(
    values: readonly string[],
    format: (value: string, index: number) => string,
  ): string[] {
    return values.map(format);
  }

  return labelValues(["Draft", "Release"], (value, index) => `${index}:${value}`);
}

这里 index 不是 index?: number，因为 labelValues 每次都会传它。回调的调用方可以只声明 value 并忽略额外参数；把 index 写成可选反而声称“实现可能不传 index”，迫使使用它的回调处理 undefined。

5. 高阶函数接收函数、返回函数，或两者兼有

export function demoHigherOrderFunction(): string[] {
  function createPrefixer(prefix: string): (value: string) => string {
    return (value) => `${prefix}:${value}`;
  }

  const prefixNote = createPrefixer("note");
  return ["draft", "release"].map(prefixNote);
}

createPrefixer 返回函数，因此是高阶函数；map 接收函数，也同样是高阶函数。prefixNote 闭包捕获 prefix，但它的公开函数类型只描述调用参数与返回值，不列出闭包内部状态。

6. 泛型参数表示类型关系，不是未知值

export function demoGenericFirst(): string | undefined {
  function first<T>(values: readonly T[]): T | undefined {
    return values[0];
  }

  return first(["Draft", "Release"]);
}

T 是一个类型参数。调用时 TypeScript 从 string[] 推断 T 为 string，所以返回值是 string | undefined。若改传 number[]，同一实现会返回 number | undefined。T 在输入元素与返回值之间保存对应关系，输出 JavaScript 时会被擦除。

7. any 接受所有类型，却丢失对应关系

export function demoGenericIdentity(): { id: string; title: string } {
  function identity<T>(value: T): T {
    return value;
  }

  const note = { id: "n1", title: "Draft" };
  return identity(note);
}

identity 的输入与输出必须是同一个 T，因此返回对象仍保留 id 和 title。若签名是 (value: any) => any，编译器无法保证返回类型与输入相同，后续属性访问会继续传播 any。

8. 多个类型参数分别连接输入与输出

export function demoGenericMap(): number[] {
  function mapValues<Input, Output>(
    values: readonly Input[],
    transform: (value: Input) => Output,
  ): Output[] {
    return values.map(transform);
  }

  return mapValues(["Draft", "Release"], (title) => title.length);
}

Input 从字符串数组推断为 string，Output 从回调返回值推断为 number。两个名称只是占位符，关键是它们分别复用在哪些位置。只有出现一次、没有建立关系的类型参数通常不需要存在。

9. 显式类型实参只在推断不足或你要锁定契约时使用

export function demoTypeArgumentInference(): string[] {
  function repeat<T>(value: T, count: number): T[] {
    return Array.from({ length: count }, () => value);
  }

  const inferred = repeat("Draft", 2);
  const explicit = repeat<string>("Release", 1);
  return [...inferred, ...explicit];
}

第一行调用已能从 Draft 推断 T，所以显式写 <string> 没有额外价值。优先让推断工作；只有没有足够值信息或需要更宽的预期类型时再手写类型实参。

10. 重载签名描述几个不同的合法调用形状

export function demoOverloads(): string[] {
  function createLookup(value: string): { kind: "id"; id: string };
  function createLookup(value: number): { kind: "index"; index: number };
  function createLookup(
    value: string | number,
  ): { kind: "id"; id: string } | { kind: "index"; index: number } {
    return typeof value === "string"
      ? { kind: "id", id: value }
      : { kind: "index", index: value };
  }

  const byId = createLookup("n1");
  const byIndex = createLookup(2);
  return [byId.id, String(byIndex.index)];
}

前两行是调用方可见的 overload signatures：字符串调用精确返回 id 成员，数字调用精确返回 index 成员。后面的 implementation signature 必须兼容全部重载，却不能作为第三种公开调用方式。重载至少要有两个可见签名。

11. 联合、泛型与重载解决不同关系

工具适合的问题本课示例
联合参数多个输入走同一返回类型与实现string | number 后统一返回 string
泛型多个位置必须保持某种类型对应关系输入 T 数组，输出仍是 T 数组
重载几种调用形状具有不同且精确的返回契约string 返回 id，number 返回 index

能用联合准确表达时优先联合；能用一个泛型关系表达时不要枚举大量重载。重载用于调用形状确实不同且需要分别展示返回契约的边界。

12. createFilter 同时连接回调、输入数组与输出数组

export function demoGenericFilter(): string[] {
  function createFilter<T>(
    predicate: (value: T) => boolean,
  ): (values: readonly T[]) => T[] {
    return (values) => values.filter(predicate);
  }

  const selectLongTitle = createFilter((title: string) => title.length >= 7);
  return selectLongTitle(["Draft", "Release", "TypeScript"]);
}
  1. createFilter 接收一个判断 string 的函数，因此 T 推断为 string。
  2. 它返回一个闭包；闭包保留 predicate，并要求 readonly string[]。
  3. 调用返回函数后，原生 filter 对每个标题调用 predicate。
  4. filter 创建新的 string[]；原数组不变，未选中的值不会进入结果。
最小实现：课程需要训练类型关系，不需要重写数组过滤算法。用泛型签名表达关系，把逐元素工作交给已经存在的 Array.prototype.filter。

TypeScript 重载与 Java 方法重载不同：输出 JavaScript 只有一个函数体，运行时必须自己检查参数。它更接近 Python 类型检查器的 @overload，但 TypeScript 的实现紧跟在签名之后。

补充观察与运行

示例 A：void 回调表示调用方忽略返回值

export function demoIgnoredCallbackReturn(): string[] {
  const visited: string[] = [];

  function visit(
    values: readonly string[],
    callback: (value: string) => void,
  ): void {
    for (const value of values) {
      callback(value);
    }
  }

  visit(["Draft", "Release"], (value) => visited.push(value));
  return visited;
}

push 返回数组的新长度，但传给 () => void 仍然合法：visit 承诺忽略回调结果，不是要求回调在运行时必须返回 undefined。显式声明为 void 的普通函数仍不能把有值返回作为自己的公开结果。

示例 B：联合参数比同返回类型的重载更容易组合

export function demoUnionInsteadOfOverload(): number {
  function getLength(value: string | readonly unknown[]): number {
    return value.length;
  }

  const input: string | readonly unknown[] = "Draft";
  return getLength(input);
}

两个输入都只需要 length 且返回 number，联合已经完整表达契约；它还能直接接受联合变量。分别写 string 与数组重载反而可能让联合变量无法匹配任何单个重载。

常见误区

  1. 把函数类型箭头当成函数实现。 类型中的箭头只描述返回类型，不会创建函数。
  2. 给回调参数随手加问号。 可选表示接收方可能省略该实参，不是“使用者可以忽略”。
  3. 用 any 冒充泛型。 any 接受所有输入但不会保留输入与输出的对应关系。
  4. 为每个具体类型复制一份实现。 行为相同且只需保持类型关系时使用一个泛型函数。
  5. 手动写所有可推断的类型实参。 它增加噪声，还可能把调用锁得比实际需要更窄。
  6. 只写一个重载签名。 实现签名对调用方不可见；重载必须有至少两个公开签名。
  7. 重载能写就不用联合。 同一返回契约通常由联合参数表达得更简单、更可组合。
  8. 把泛型 T 当成运行时变量。 它在编译后不存在，不能打印、比较或用 instanceof 检查。

Learning Contract

进入泛型约束、keyof 与类型查询前，你应当能够：

  • 读写函数类型表达式，并指出参数与返回类型各自的位置。
  • 根据接收方签名预测回调参数的上下文类型、调用次数和返回值用途。
  • 解释高阶函数与闭包如何在运行时组合。
  • 用一个或多个泛型参数表达输入、回调和输出之间的对应关系。
  • 判断何时依赖类型实参推断，何时需要显式类型实参。
  • 解释 overload signature、implementation signature 与实际单一 JavaScript 函数体的关系。
  • 在联合、泛型和重载之间选择最简单且准确的契约。

Lab 09：创建可复用的泛型过滤函数

由你创建或修改：创建 src/lesson-09.ts，把本课案例、改写和 Lab 都保存在这里。

不要修改：tests/lessons.test.ts 与 scripts/；它们是课程验收工具。

你要交付什么

导出下面的泛型高阶函数，并保持参数名与类型关系清晰：

createFilter<T>(
  predicate: (value: T) => boolean,
): (values: readonly T[]) => T[]

运行规则

  1. 调用 createFilter 时保存 predicate，并返回一个新的过滤函数。
  2. 调用返回函数时，把 values 交给原生 values.filter(predicate)。
  3. predicate 按输入顺序对每个元素执行一次；true 保留，false 排除。
  4. 返回新的 T[]，不修改输入数组。

类型规则

  • 只使用一个类型参数 T，把 predicate 参数、输入元素和输出元素连接起来。
  • 输入必须接受 readonly T[]，因此普通数组和 as const 数组都能传入。
  • predicate 必须返回 boolean，不能改成 any、unknown 或任意值。
  • 不要加入泛型约束、keyof、重载、去重、排序或异常处理。

本课只建立函数组合与类型关系。第 10 课才会讨论泛型约束、keyof、索引访问类型和 typeof 类型查询。

三层提示

提示 1 · 先写外层泛型签名

在函数名后写 <T>，predicate 类型是 (value: T) => boolean，返回类型本身也是一个函数类型。

提示 2 · 返回闭包而不是过滤结果

createFilter 第一次调用还没有 values；返回 (values) => ...，该箭头函数会捕获 predicate。

提示 3 · 复用原生 filter

返回函数体只需 values.filter(predicate)。filter 已经保证新数组、输入顺序与逐元素判断。

概念测验

泛型参数 T 在 createFilter 中表达什么？

折叠完整答案与逐行解析

显示完整答案 
/** @lab */
export function createFilter<T>(
  predicate: (value: T) => boolean,
): (values: readonly T[]) => T[] {
  return (values) => values.filter(predicate);
}
第 1–2 行
T 在每次 createFilter 调用中代表一种元素类型；predicate 必须接收该类型并返回 boolean。
第 3 行
外层函数返回另一个函数；返回函数接受只读 T 数组并产生新的可变 T 数组。
第 4 行
箭头函数捕获 predicate，原生 filter 负责按顺序调用它并创建结果数组。
第 5 行
外层函数结束；没有额外状态、重载或自定义循环。
